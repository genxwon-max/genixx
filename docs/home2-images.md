# /home2 홍보 화면 사진 발주서

`/home2`에 들어가는 사진 7장의 파일명·규격·생성 지시문입니다.
Gemini·GPT 같은 이미지 생성 도구에 **「지시문」 칸을 그대로 붙여 넣으면** 됩니다.

## 넣는 방법

받은 파일을 아래 이름 그대로 `public/`에 넣으면 끝입니다. 코드는 손대지 않아도 됩니다.

```
public/promo-parent-worry.png
public/promo-trace-write.png
...
```

- 확장자는 `png` `webp` `jpg` `jpeg` `avif` 중 아무거나 됩니다. **웹에는 `webp`가 가장 가볍습니다.**
- 파일이 없으면 화면에 「사진 자리 · 파일명」 자리표가 뜹니다. 지금 상태가 그렇습니다.
- 크기는 코드가 알아서 읽습니다. 다만 **가로세로 비율은 지켜 주세요** — 다르면 가운데를 기준으로 잘립니다.
- 한 장에 **400KB 아래**를 권합니다. 생성물이 크면 [squoosh.app](https://squoosh.app)에서 webp로 줄이면 됩니다.

## 모든 사진에 공통으로 붙일 조건

지시문 끝에 아래 문단을 그대로 덧붙이세요. 일곱 장이 한 세트로 보이게 하는 부분입니다.

```
스타일: 자연광이 부드럽게 들어오는 실내, 다큐멘터리 사진 톤. 연출된 스톡 사진
특유의 과장된 미소나 정면 응시 없이, 그 순간에 몰입해 있는 자연스러운 모습.
색감은 따뜻한 중성톤에 남색과 옅은 파랑이 은은하게 섞여 있고 채도는 낮게.
배경은 단순하고 어수선하지 않게. 얕은 심도로 인물이나 손에 초점.
텍스트·로고·워터마크 없음. 초현실적 보정이나 만화풍 없이 실사.
인물은 한국 초등학생(만 9~12세)과 한국 성인.
```

**넣지 말아야 할 것** — 지시문에 이렇게 덧붙이면 도움이 됩니다.

```
피할 것: 시험지·OMR 카드·성적표·석차·트로피·메달·1등·상장, 학원 강의실 칠판,
울거나 좌절한 표정, 부모가 아이를 다그치는 장면, 뇌 그래픽이나 전구 아이콘,
로봇·홀로그램 같은 미래풍 UI 오버레이.
```

> 왜 피하나 — 이 서비스는 등수를 매기지 않는다는 게 핵심 약속입니다. 진단 윤리 헌장이
> 「줄 세우지 않는다」를 명시하고 있어서, 사진에 성적표나 트로피가 들어가면 화면 전체가
> 하는 말과 사진이 서로 다른 말을 하게 됩니다.

## 1. `promo-parent-worry`

| | |
|---|---|
| **자리** | 「이런 고민에서 시작하셨다면」 섹션 왼쪽 |
| **비율** | 4:3 (권장 1600×1200) |
| **역할** | 페이지에서 처음 나오는 사람 얼굴. 학부모가 자기 상황을 알아보게 하는 자리 |

**지시문**

```
집 식탁에 나란히 앉은 한국인 학부모와 초등학교 4학년쯤 되는 아이. 아이가 펼친
공책을 둘이 함께 들여다보고 있고, 부모는 채점하듯 보는 것이 아니라 아이가 무슨
생각으로 이걸 썼는지 궁금해하는 표정. 아이는 손가락으로 공책의 한 부분을 가리키며
설명하는 중. 창문에서 오후 햇살이 옆으로 들어오고 식탁에는 머그컵 하나 정도만.
카메라는 살짝 옆에서, 두 사람의 시선이 공책으로 모이는 구도.
```

## 잘 안 나올 때

- **아이 얼굴이 어색하게 나오면** — 얼굴을 빼고 손·뒷모습·옆모습으로 다시 요청하세요.
  1·3·4번은 원래 얼굴이 없어도 되는 구도입니다.
- **너무 스톡 사진 같으면** — 지시문에 `카메라를 의식하지 않는 순간, 살짝 흔들리거나
  비대칭인 구도`를 덧붙이면 나아집니다.
- **한국인처럼 안 나오면** — `한국 서울의 일반 가정집`, `한국 초등학교 교실`처럼 장소를
  구체적으로 박아 주세요.
- **일곱 장의 톤이 제각각이면** — 마음에 드는 한 장을 먼저 뽑고, 나머지는 그 이미지를
  참조로 붙여서 `이 사진과 같은 색감과 조명으로`라고 요청하는 편이 빠릅니다.
